Local broker

Authoring stays on your PC / LAN. Do not point Director at the public Home Assistant broker.

Python broker (this PC)

Director ships its own local MQTT broker. Leave this running while you author:

cd director\tools
python -m pip install -r requirements.txt
python run_local_broker.py

It serves TCP 1883 for the panel and WebSocket 9001 for this page. If 1883 is already in use, stop the other MQTT service first.

This PC’s LAN IP

Shown automatically while the Python broker is running. Paste it on the panel.

waiting…

On the panel: /mqtt → Director → paste this IP → Connect to Director. Port, prefix, and Subscriber are filled for you. No password. Several panels on the same private AP can all subscribe here and follow the Launch grid. Your Normal broker settings stay saved — leave Director mode to publish or subscribe on the house topic again.

FlowLocal

Appliance broker

This copy talks to the ESP32 FlowLocal box, not a PC broker.

1. Join Wi-Fi PatternflowLocal (password patternflow).

2. Open Director from the box: http://192.168.66.1/director/ (do not double-click this file on the PC — the browser needs http).

3. Connect uses ws://192.168.66.1:9001, prefix patternflow, empty user/password.

On the panel: /mqtt → Director → host 192.168.66.1 port 1883 → Connect to Director.

Then use the Launch tab.

Broker connection

disconnected

Local Director broker: leave user/password empty, prefix patternflow. Connect only opens the socket. Pattern inventory is optional — use Load patterns from panel when you want it. That query is a broadcast on the prefix, so every Director-mode panel will answer; skip it when several devices are live and you only need to play the deck.

Panel HTTP base is used for Install used patterns / Send show — the panel pulls files from FlowLocal over HTTP. Default http://patternflow.local; use the panel’s LAN IP if mDNS fails on the tablet.

Performance timeline

PFST v2 · 0.1 s · ease

Load from the panel or search the catalog, then remove anything you will not use. That shortlist is what appears in the Pattern dropdown for cues — it is what the artist could use. Click a name to preview it on the device (MQTT). Use × to drop it from the list.

    0:00.00

    Cue editor

    Set Length for the timeline span. Click the seconds bar to move the playhead (preview only). Click a lane to plant a block there; select a block and use the sliders/numbers above — drag previews the full aligned look on the panel; release (or change the number) writes that channel into the timeline. Changing other sliders plants blocks on those channels at the playhead. Capture snapshot stores the full active look at the playhead. New shows are PFST v2 (0.1 s grid). Tick Ease on a param cue so those channels glide to the next cue instead of holding.

    Leave off for hard jumps (mode knobs). On for smooth sweeps.

    Launch deck

    4×4 clip grid on the local Director broker. Edit previews on every subscribed panel, then Store writes the pad (that is what autosaves). Play fires clips now, or quantized to BPM in 4/4. Layers: Snapshots, K1–K4 (param/1..4, pads already hold 0…1000), and Message. Knob layers always hit that channel — they do not guess hue or speed. This is not a .pfs show.

    Pad editor

    The panel follows these controls. Store writes the selected pad. Autosave runs every 3 stores. K1–K4 start filled 0…1000; Store can retune a pad.

    Performance mode is on: launch-only view, play mode forced, lighter UI for the tablet.

    Performance file

    Open and save a .pfs table — the same file the panel plays on /show. New shows are PFST v2: cue times in 0.1 s steps, optional EASE so absolute params (0..1000) lerp between cues. Older v1 files still open; use Upgrade to v2 / Compress staircases to modernize a dense 1 Hz bake. Knob names come from the local catalog cache js/patterns-catalog.json.

    When the timeline is done, Install used patterns to panel asks the panel to pull matching .pfm files from FlowLocal’s patterns/ library (set Panel HTTP base on Connect). Send show to panel saves the current .pfs to FlowLocal then pulls it onto the panel’s /shows.

    On FlowLocal, Save and Open use the USB stick library (shows/). Tablet download/upload still works via the local buttons.
