          Panels

            Wire MIDI to the panels Shift+A or right-click adds a node. Drag from socket to socket to connect.

            Plug the hub's USB jack into the computer and a MIDI device named Patternflow Ensemble appears. It is the same cable as the console.

            This is the plain mapping. It is what applies while Nodes is off; with Nodes on, the controllers the graph names go to the graph instead, and everything else still works this way.

            Channels

            1 – 15The panel with that number
            16Every panel

            Computer → panels

            CC 20 – 23Knobs K1 – K4, absolute. 0 – 127
            CC 24 – 27Knobs K1 – K4, relative. 64 is no motion, 65 one click up, 63 one click down
            CC 28Brightness. 0 – 127 (darkest to brightest)
            Program ChangeThe pattern number

            Panels → computer

            CC 24 – 27On channel n, panel n's K1 – K4, whenever what that panel shows changes (a hand, a ripple arriving, the console)
            Program ChangeOn channel n, panel n's pattern
            Channel 16The value somebody just turned, anywhere: the ensemble as one instrument

            A knob value the computer sent does not come back; a pattern does. Brightness is received only. Panels numbered 16 and up are not on MIDI.

            Patterns

            1. Open Patterns at the top.
            2. Copy the address of a pattern or a deck on the community and paste it, then Add. Knob values on the end of the address are fine. Several at once work, and one deck address brings the whole deck.
            3. Drag the rows into order. The order is the panels' pattern numbers.
            4. Tick the panels on the right and Install. What those panels held is cleared and replaced by the set.
            5. When it is done every row has a ▶: it plays that pattern on every panel.

            This computer fetches the files from the community and sends them to the panels through the hub. It needs the internet, and the USB cable to the hub.

            Shows (performances)

            A show is a recorded loop of patterns and knob moves that a panel plays by itself. A deck with a performance attached brings it along, and Install stores it on the panels too. A .pfs file can be dropped in as well. On the Stage, select a panel and use Shows on the right: play (▶), stop (■), loop. With several panels selected it goes to all of them.

            ● Record: select panels, press it, play (by hand, the console or MIDI), then ■ Stop. Each selected panel loops what it did, at once. A recording can be ten minutes long; very busy ones are stored a little coarser. A panel keeps four recordings and drops the oldest. The ✕ beside the list deletes the chosen show from the panel.

            The Shows page keeps every recording and imported show. Choose one to see its four knob curves and where the pattern changes, then cut it (start, end), stretch it (longer is slower), swap or invert knobs, or put it on another pattern. The recording itself is never changed, so it can always be reset. Put on and play sends it to the ticked panels.

            A panel playing a show is out of the ensemble for that long: its knobs move no other panel, and it takes no values from the others. Stop the show and it returns to what the ensemble is showing.

            Wire the way from a MIDI controller to the panels. Every edit goes to the hub, which then runs the graph by itself, with or without this page. The hub evaluates the graph once for every panel: mix in a Panel Info output (order, position, random) and each panel gets a different value from the same signal.

            Nodes: On / Off is the switch. Off, the hub keeps the graph but ignores it, and MIDI works the plain way (the MIDI tab). On, the controllers the graph names belong to the graph; everything else still works the plain way.

            Controls

            Shift + AAdd a node. Also right-click, double-click on empty space, or + Add
            Drag a socketConnect. Drag a connected input away to disconnect. Dropping on a node takes its first free input
            Ctrl + right-dragCut Links: every wire the stroke crosses is removed. Ctrl + left-drag from empty space does the same
            Drag a titleMove. Shift + click selects several, A all, Alt + A none
            Shift + DDuplicate. Ctrl + C / V / X copy, paste (at the pointer), cut. Wires between the copied nodes come along
            X · DeleteDelete the selected nodes
            Drag empty space · wheelPan · zoom. Home frames everything

            Nodes

            MIDI CCOne controller: a channel and a CC number, as 0–1. Learn, then move the controller, and the numbers fill in. Name it. Its slider moves the value without the controller
            Value · Time · LFO · NoiseA number · seconds running · a wave (sine, triangle, saw, square) · a slow wander
            Panel InfoOf the panel being evaluated: its number, order (0–1), position on the map, and a random number of its own
            Panel KnobsWhere that panel's own K1–K4 are now (a hand's turn as an input)
            Math · ExpressionAdd, multiply, invert … · a formula you type
            Map Range · Clamp · Mix0–1 onto 0.2–0.8 · keep inside limits · between two values
            Smooth · Snap · SwitchFollow slowly · quantise to steps · choose by a condition
            Panel OutputK1–K4 (0–1), Pattern (index), Brightness (0–1). Only connected sockets are sent. Click the line under the title to choose the panels: all, or some. Duplicate it for different panels

            Expression

            a b c d (the inputs) t (seconds) pi · + - * / % ^ > < · sin cos abs floor round fract sqrt sign noise min max pow mod clamp(x, lo, hi) mix(a, b, f) select(cond, yes, no)

            For example 0.5 + 0.5 * sin(t + a * 6)

            A knob turned by hand stays where the hand left it until the graph's value for it moves again. A panel that is playing a show takes nothing from the graph.
